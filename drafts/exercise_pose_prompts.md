# Exercise pose prompts for AI drawing

Each prompt below works on its own: paste one, get one picture. Save each picture under its file name.

**Tips for a matching set**
- Make `preg_breathing` first. Then give that picture to the AI as a "character reference" or "style reference"
  with every following prompt (most tools have this option), so it stays the same woman in the same style.
- Check every picture: AI often draws extra fingers, twisted knees or a wrong number of limbs. Redo any that look wrong.
- The prompts ask for a plain white background; it can be removed afterwards (e.g. remove.bg) to get a transparent PNG.
- The prompts ask for no text: Arabic labels, if any, are added by the app.
